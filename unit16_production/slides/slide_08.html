PART 08
ശരാശരി സ്ഥിരച്ചെലവ് AVERAGE FIXED COST (AFC)
ACADEMIC HUB SPECIAL

ശരാശരി സ്ഥിരച്ചെലവും സ്പ്രെഡിംഗ് ഇഫക്റ്റും

Average Fixed Cost: AFC = F / q & Spreading Effect

ഉത്പാദന യൂണിറ്റൊന്നിനുള്ള സ്ഥിരച്ചെലവ് Continuous Decline in Per-Unit Fixed Burden
ഉത്പാദിപ്പിക്കുന്ന യൂണിറ്റൊന്നിന് വരുന്ന സ്ഥിരച്ചെലവാണ് AFC. സമവാക്യം: AFC = F / q. ഉത്പാദനം കൂടുംതോറും ഒരേ സ്ഥിരച്ചെലവ് കൂടുതൽ യൂണിറ്റുകളിലേക്ക് വിഭജിക്കപ്പെടുന്നു (Spreading Effect). അതിനാൽ ഉത്പാദനം കൂടുമ്പോൾ AFC തുടർച്ചയായി കുറഞ്ഞുകൊണ്ടിരിക്കുന്നു.
Average Fixed Cost (AFC = F / q) measures fixed cost per unit of output. As output expands, fixed overhead is distributed across more units—the classic 'spreading effect'. Consequently, AFC monotonically declines as q increases, never touching the axis.
