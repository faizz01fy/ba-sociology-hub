ഒരേ പലിശയും വ്യത്യസ്ത തുകയും SAME SI EARNED FROM SPLIT AMOUNTS
ACADEMIC HUB SPECIAL

ഒരു തുക രണ്ട് ഭാഗങ്ങളായി നിക്ഷേപിക്കുമ്പോൾ തുല്യ പലിശ ലഭിക്കൽ

Ratio of Principals P₁ : P₂ = 1/(R₁T₁) : 1/(R₂T₂)

SI₁ = SI₂ ആയാൽ തുകകൾ R×T യുടെ വിപരീത അനുപാതത്തിൽ! Equal Interest Split → Invert Each (Rate × Time) Product
• രണ്ട് നിക്ഷേപങ്ങളിൽ നിന്ന് ഒരേ പലിശ (SI₁ = SI₂) കിട്ടിയാൽ: P₁ : P₂ = 1/(R₁T₁) : 1/(R₂T₂). • എന്നാൽ കാലാവധി കഴിയുമ്പോൾ രണ്ട് ആകെ തുകയും (A₁ = A₂) തുല്യമായാൽ: P₁ : P₂ = 1/(100+R₁T₁) : 1/(100+R₂T₂).
Splitting Sum S into parts receiving Equal Interest: P₁ : P₂ = 1/(R₁T₁) : 1/(R₂T₂). Splitting Sum S into parts yielding Equal Maturity Amounts: P₁ : P₂ = 1/(100 + R₁T₁) : 1/(100 + R₂T₂)!
തുല്യ പലിശാ വിഭജനം • Equal SI Split Formula
