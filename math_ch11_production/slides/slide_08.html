കള്ളത്തൂക്ക ലാഭം DISHONEST DEALER / FALSE WEIGHT
ACADEMIC HUB SPECIAL

കള്ളത്തൂക്ക ലാഭം (False Weight): വാങ്ങിയ വിലയ്ക്ക് വിൽക്കുന്നതിലെ തട്ടിപ്പ്!

LMS Formula: Gain % = [Error / (True Weight − Error)] × 100

1 കിലോഗ്രാമിന് പകരം 900 ഗ്രാം കൊടുത്താൽ ലാഭം 10% അല്ല! Gives 900g Instead of 1000g → Gain = (100 / 900) × 100 = 11 1/9%!
വാങ്ങിയ വിലയ്ക്ക് വിൽക്കുന്നുവെന്ന് പറഞ്ഞ് 1,000 ഗ്രാമിന് പകരം 900 ഗ്രാം മാത്രം തൂക്കിക്കൊടുക്കുന്ന കച്ചവടക്കാരന്റെ ചെലവ് (CP) 900 ഗ്രാം മാത്രമാണ്, പക്ഷെ കാശ് വാങ്ങുന്നത് 1,000 ഗ്രാമിന്റേതാണ്! Gain % = [100 / (1000 − 100)] × 100 = (100 / 900) × 100 = 11 1/9%!
False Weight Logic: Dealer pays cost for only the False Weight actually given (900g), yet charges for 1000g! Gain % = [Error / True Weight Delivered] × 100 = (100 / 900) × 100 = 11.11% (not 10%!).
