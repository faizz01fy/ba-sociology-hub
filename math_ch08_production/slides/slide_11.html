Converting Coin Count Ratios into Value Ratios (Rupees & Paise)

മൂല്യം = നാണയത്തിന്റെ എണ്ണം × ഒരു നാണയത്തിന്റെ വില Rs. 1, 50p, 25p Coins in Count Ratio 2:3:4 → Value Ratio 2 : 1.5 : 1
ബാഗിൽ 1 രൂപ, 50 പൈസ, 25 പൈസ നാണയങ്ങളുടെ എണ്ണം a : b : c അനുപാതത്തിൽ ആണെങ്കിൽ, അവയുടെ ആകെ മൂല്യം കാണാൻ ഓരോ നാണയത്തിന്റെയും തുക കൊണ്ട് ഗുണിക്കുക (അല്ലെങ്കിൽ പൈസയാക്കി മാറ്റുക): Value = (100a : 50b : 25c) പൈസ.
If coin counts are given while total Rupees is fixed, multiply each coin ratio by its denomination value (e.g., 100p, 50p, 25p) to equate to total paise. Conversely, divide value ratio by coin value to get counts!
