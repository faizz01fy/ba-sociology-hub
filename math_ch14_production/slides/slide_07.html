3-വർഷ CI − SI വ്യത്യാസം 3-YEAR CI − SI DIFFERENCE LAW
ACADEMIC HUB SPECIAL

3 വർഷത്തെ CI − SI വ്യത്യാസം: D₃ = P(R/100)² × (3 + R/100)

Also Written Cleanly as D₃ = [P · R² · (300 + R)] / 100³

അല്ലെങ്കിൽ 3-വർഷ ട്രീ രീതി (Tree Method: 3a + 3b + c) 3a = SI | CI − SI = 3b + c Where b = R% of a, c = R% of b
3 വർഷത്തെ വ്യത്യാസത്തിന്: D₃ = P(R/100)² × [(300 + R) / 100]. ഉദാഹരണം: 10,000 രൂപയ്ക്ക് 10%-ൽ 3 വർഷം: 10,000 × (1/100) × (310/100) = 310 രൂപ (അല്ലെങ്കിൽ 3(100) + 10 = 310 രൂപ!).
For 3 years: D₃ = P(R/100)² × (3 + R/100). Using Tree Shortcut on Rs. 10,000 @ 10%: Yr1 SI (a) = 1,000; R% of a (b) = 100; R% of b (c) = 10 → 3-Yr Diff = 3b + c = 3(100) + 10 = Rs. 310!
