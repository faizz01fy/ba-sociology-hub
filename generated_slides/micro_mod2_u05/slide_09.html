ACADEMIC HUB SPECIAL

സ്വഭാവം 3: രണ്ട് ഇൻഡിഫറൻസ് കർവുകൾ പരസ്പരം ഛേദിക്കില്ല

Property 3: Two Indifference Curves Can Never Intersect

ഛേദിച്ചാലുള്ള യുക്തിഭംഗം (Contradiction) Logical Inconsistency of Intersecting ICs
രണ്ട് കർവുകൾ IC1 ഉം IC2 ഉം 'A' എന്ന ബിന്ദുവിൽ ഛേദിക്കുന്നു എന്ന് കരുതുക. IC1 ലെ ബിന്ദുക്കളായ A യും B യും തുല്യമാണ് (A ~ B). IC2 ലെ A യും C യും തുല്യമാണ് (A ~ C). സംക്രമണതാ നിയമപ്രകാരം B യും C യും തുല്യമാകണം (B ~ C).
Assume IC1 and IC2 intersect at point A. Then A ∼ B on IC1 and A ∼ C on IC2, which via transitivity implies B ∼ C. But bundle C clearly has more goods than B, creating an absurdity.
വിപരീത അനുമാന തെളിവ് Proof by Transitivity Violation
എന്നാൽ ഗ്രാഫിൽ C എന്ന ബണ്ടിലിൽ B യേക്കാൾ കൂടുതൽ അളവ് സാധനങ്ങളുണ്ട്. മോണോടോണിസിറ്റി പ്രകാരം C > B ആയിരിക്കണം. ഒരേസമയം C ~ B യും C > B യും വരുന്നത് അസാധ്യമാണ്. അതിനാൽ രണ്ട് IC-കൾ ഒരിക്കലും ഛേദിക്കില്ല.
Since bundle C contains strictly more of commodity Y than B, monotonicity requires C ≻ B, completely contradicting B ∼ C. Hence ICs cannot intersect.
