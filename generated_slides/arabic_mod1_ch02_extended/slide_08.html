ഫിഅ്ലുൽ അംറ് FI'L AL-AMR (IMPERATIVE)
ACADEMIC HUB SPECIAL

ഫിഅ്ലുൽ അംറ്: കൽപ്പന ക്രിയകളുടെ നിർമ്മാണ നിയമങ്ങൾ

Imperative Verb (Fi‘l al-Amr): Derivation from Second-Person Muḍāri‘

അംറ് നിർമ്മിക്കുന്ന ഘട്ടങ്ങൾ Algorithmic Steps to Form Fi‘l al-Amr
1. രണ്ടാം പുരുഷ മുളാരിഅ് എടുക്കുക (ഉദാ: തക്തുബു - تَكْتُبُ). 2. ആദ്യത്തെ മുളാരിഇന്റെ അക്ഷരമായ 'താ' (ت) ഒഴിവാക്കുക -> ക-തു-ബു (كْتُبُ). 3. ആദ്യ അക്ഷരത്തിന് സുക്കൂൻ ആയതിനാൽ ഉച്ചരിക്കാനായി ഹംസത്തുൽ വസ്ൽ (ٱ) ചേർക്കുക. 4. അവസാന അക്ഷരത്തിന് സുക്കൂൻ നൽകുക -> ഉക്തുബ് (اُكْتُبْ - നീ എഴുതുക!).
1. Take 2nd person muḍāri‘ (Taktubu). 2. Drop the prefix Tā. 3. Add Hamzat al-Waṣl since first radical is unvowelled (Sākin). 4. Place Sukūn on last radical => Uktub (اُكْتُبْ).
ഹംസത്തുൽ വസ്ലിന്റെ സ്വര നിയമം Vocalization of Hamzat al-Waṣl (Ḍammah vs Kasrah)
മുളാരിഇന്റെ രണ്ടാമത്തെ അക്ഷരത്തിന് (ഐൻ കലിമ) ളമ്മത്ത് ആണെങ്കിൽ ഹംസയ്ക്ക് ളമ്മത്ത് നൽകണം (ഉദാ: യക്തുബു -> ഉക്തുബ്). ഫത്‌ഹത്തോ കസ്രത്തോ ആണെങ്കിൽ ഹംസയ്ക്ക് കസ്രത്ത് നൽകണം (ഉദാ: യജ്‌ലിസു -> ഇജ്‌ലിസ്, യഫ്തഹു -> ഇഫ്തഹ്).
Hamzat al-Waṣl takes Ḍammah if the medial radical has Ḍammah (Yaktubu -> Uktub); it takes Kasrah if the medial radical carries Fatḥah or Kasrah (Yajlisu -> Ijlis; Yaftahu -> Iftah).
