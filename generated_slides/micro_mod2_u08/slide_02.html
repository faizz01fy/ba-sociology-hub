The Budget Constraint: Inequality Formulation & Budget Set

ബജറ്റ് പരിമിതി അസമത്വം Budget Constraint Inequality
ഒരു ഉപഭോക്താവിന് രണ്ട് സാധനങ്ങൾക്കായി ചെലവഴിക്കാൻ കഴിയുന്ന ആകെ തുക അയാളുടെ വരുമാനത്തിന് തുല്യമോ അതിൽ കുറവോ ആയിരിക്കണം: Px·X + Py·Y ≤ M. ഇവിടെ Px, Py വിലകളും M വരുമാനവുമാണ്.
Formulated as Px·X + Py·Y ≤ M, stating that total expenditures on goods X and Y cannot exceed the consumer's disposable monetary income M.
ബജറ്റ് സെറ്റ് (Budget Set / Opportunity Set) Budget Set / Feasible Opportunity Set
നിലവിലുള്ള വരുമാനത്തിലും വിലകളിലും ഉപഭോക്താവിന് താങ്ങാൻ കഴിയുന്ന (Affordable) എല്ലാ സാധന സങ്കരങ്ങളുടെയും ആകെത്തുകയാണ് ബജറ്റ് സെറ്റ്. ഗ്രാഫിൽ ബജറ്റ് രേഖയ്ക്കുള്ളിലുള്ള ത്രികോണ മേഖലയാണിത്.
The collection of all affordable consumption bundles satisfying the budget inequality, geometrically representing the feasible shaded triangular region below the budget line.
