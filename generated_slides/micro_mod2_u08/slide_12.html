ACADEMIC HUB SPECIAL

പരിഹരിച്ച ഗണിത പ്രശ്നം: ഒപ്റ്റിമൽ ചോയ്സ് കണ്ടെത്തൽ

Complete Solved Numerical Problem: Maximizing Consumer Choice

പ്രശ്നം: U = X·Y, Px = 2, Py = 4, M = 80 Problem Specification & Parameters
ഒരു ഉപഭോക്താവിന്റെ യൂട്ടിലിറ്റി ഫംഗ്ഷൻ U = X·Y ആണ്. Px = 2 രൂപ, Py = 4 രൂപ, വരുമാനം M = 80 രൂപ. സന്തുലിതാവസ്ഥയിൽ ഉപഭോക്താവ് വാങ്ങുന്ന X ന്റെയും Y ന്റെയും ഒപ്റ്റിമൽ അളവുകൾ കണ്ടെത്തുക.
Given utility function U = X·Y, price of X Px = 2, price of Y Py = 4, and income M = 80, compute the utility-maximizing equilibrium bundle (X*, Y*).
ഘട്ടങ്ങളായുള്ള പരിഹാരം Step-by-Step Mathematical Derivation
MRSxy = MUx/MUy = Y/X. സമനിലയിൽ MRSxy = Px/Py -> Y/X = 2/4 = 1/2 -> X = 2Y. ബജറ്റ് സമവാക്യത്തിൽ നൽകിയാൽ: 2(2Y) + 4Y = 80 -> 8Y = 80 -> Y* = 10 യൂണിറ്റ്. X* = 2(10) = 20 യൂണിറ്റ്.
MRSxy = MUx/MUy = Y/X = Px/Py = 2/4 => X = 2Y. Substitute into budget: 2(2Y) + 4Y = 80 => 8Y = 80 => Y* = 10. Then X* = 2(10) = 20 units.
