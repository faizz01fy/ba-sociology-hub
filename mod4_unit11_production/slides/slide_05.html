PART 05
MR < P തെളിവ് OUTPUT VS PRICE EFFECT
ACADEMIC HUB SPECIAL

എന്തുകൊണ്ട് MR ഡിമാൻഡ് കർവിന് താഴെയാകുന്നു?

Output Gain (B) Minus Price Loss on Existing Units (C)

MR = P + (ΔP/ΔQ) × Q സമവാക്യം ΔR = P₂ − (P₁ − P₂)Q = Area B − Area C
അധികമായി വിൽക്കുന്ന 1 യൂണിറ്റിൽ നിന്ന് ലഭിക്കുന്ന വരുമാനമാണ് ഔട്ട്പുട്ട് ഇഫക്റ്റ് (P₂ = ഏരിയ B). എന്നാൽ വില P₁-ൽ നിന്ന് P₂-ലേക്ക് കുറയുമ്പോൾ മുൻപ് വിറ്റുകൊണ്ടിരുന്ന Q യൂണിറ്റുകളിൽ നിന്നുണ്ടാകുന്ന നഷ്ടമാണ് പ്രൈസ് ഇഫക്റ്റ് (ΔP × Q = ഏരിയ C). അതിനാൽ MR = B − C < P ആയിരിക്കും.
Selling an extra unit gains revenue P₂ (Area B, output effect) but forces a price drop ΔP across all Q existing units (Area C = ΔP·Q, price effect). Thus MR = P + (ΔP/ΔQ)Q. Because demand slopes down (ΔP/ΔQ < 0), MR lies strictly below price.
