PART 07
MR-ഉം ഇലാസ്തികതയും MR AND ELASTICITY
ACADEMIC HUB SPECIAL

സീമാന്ത വരുമാനവും വില ഇലാസ്തികതയും (ε)

Key Formula: MR = P [ 1 + (1 / ε) ]

ഇലാസ്തിക മേഖലയിൽ മാത്രം ലാഭ പരമാവധി |ε| > 1 ⟹ MR > 0 | |ε| = 1 ⟹ MR = 0 | |ε| < 1 ⟹ MR < 0
വില ഇലാസ്തികത ε ഉം സീമാന്ത വരുമാനവും തമ്മിലുള്ള പ്രധാന സമവാക്യം: MR = P(1 + 1/ε). 1. ഡിമാൻഡ് ഇലാസ്തികമാണെങ്കിൽ (|ε| > 1): MR പോസിറ്റീവായിരിക്കും. 2. യൂണിറ്ററി ഇലാസ്തികതയിൽ (ε = −1): MR പൂജ്യമാകും. 3. ഇൻഇലാസ്തിക മേഖലയിൽ (|ε| < 1): MR നെഗറ്റീവാണ്. MC എപ്പോഴും പോസിറ്റീവായതിനാൽ, കുത്തക ഇലാസ്തിക മേഖലയിൽ മാത്രമേ പ്രവർത്തിക്കൂ.
Since MR = P(1 + 1/ε): MR is positive only where demand is elastic (|ε| > 1), zero at unitary elasticity (ε = -1), and negative where inelastic (|ε| < 1). Because MC ≥ 0, a profit-maximizing monopoly strictly operates in the elastic portion of demand.
ഇലാസ്തികതാ വിശകലനം • Elasticity Constraint
