പൂർണ്ണമത്സരവും കുത്തകയും: ക്ഷേമ താരതമ്യ പട്ടിക

Table 19.1 Proof: ΔCS = -B-C, ΔPS = B-E, ΔW = -C-E (DWL)

പാഠപുസ്തക പട്ടികയിലെ വിസ്തീർണ്ണ വിശകലനം Quantifying Efficiency Loss (P = 24 − Q, MC = 2Q)
പൂർണ്ണമത്സരത്തിൽ (Qc = 8, Pc = 16): CS = A + B + C, PS = D + E, ആകെ ക്ഷേമം W = A + B + C + D + E. കുത്തകയിൽ (Qm = 6, Pm = 18): CS = A (മാറ്റം = −B − C), PS = B + D (മാറ്റം = B − E > 0). ആകെ ക്ഷേമത്തിലെ അറ്റ നഷ്ടം ΔW = −C − E = Deadweight Loss (B = 12 കൈമാറ്റം; C+E എന്നത് ത്രികോണ നഷ്ടം). ഇത് സർക്കാർ ഇടപെടലിന് കാരണമാകുന്നു.
Competition (Qc=8, Pc=16) yields CS = A+B+C, PS = D+E. Monopoly (Qm=6, Pm=18) cuts CS to A (ΔCS = -B-C) and changes PS to B+D (ΔPS = B-E > 0). Net social welfare drops by ΔW = -C - E (DWL), providing an efficiency rationale for regulation.
